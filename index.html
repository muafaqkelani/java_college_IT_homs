1. ما هي جافا؟ (خصائص اللغة الـ 11)

تُعرّف المحاضرة لغة جافا بأنها لغة برمجة عالية المستوى (High-Level Language) تتصف بـ 11 خاصية أساسية[cite: 2]. في المذاكرات المؤتمتة أو النظري، غالباً ما يُسأل عن المصطلح الإنجليزي ومقابله أو دلالته البرمجية:

1. Simple (بسيطة)

لأنها تخلصت من تعقيدات لغات مثل C++ (مثل المؤشرات الصريحة Pointers، وحجز وتحرير الذاكرة اليدوي بفضل وجود الـ Garbage Collector).

2. Object Oriented (غرضية التوجه)

كل شيء في جافا يتمحور حول الصفوف (Classes) والأغراض/الكائنات (Objects). لا يمكن كتابة دالة في جافا خارج إطار صف.

3. Distributed (موزعة)

صُممت لتعمل في بيئات الشبكات الموزعة بسهولة وتدعم بروتوكولات مثل HTTP و FTP و RMI.

4. Multithreaded (متعددة المسالك/الخيوط)

تدعم تنفيذ عدة مهام برمجية في آنٍ واحد داخل البرنامج نفسه لتعظيم استغلال المعالج.

5. Dynamic (ديناميكية)

قادرة على التكيف مع بيئتها المتطورة وتحميل الصفوف عند الطلب في وقت التشغيل (Run-time).

6. Architecture Neutral (مستقلة عن منصات العمل/معمارية المعالج)

الكود المترجم لا يعتمد على معمارية معالج محددة (سواء كان x86 أو ARM).

7. Portable (محمولة)

يمكن نقل الكود المترجم وتشغيله على أي جهاز دون تعديل.

8. Platform Independent (مستقلة عن المنصة/نظام التشغيل)

شعار جافا الشهير "Write Once, Run Anywhere" (اكتب مرة واحدة، وشغّل في أي مكان).

9. High Performance (ذات أداء عالٍ)

بفضل استخدام المترجم الفوري (JIT - Just In Time Compiler) داخل آلة جافا.

10. Robust (متينة/قوية)

بسبب إدارتها الصارمة للذاكرة وفحص الأخطاء أثناء الترجمة (Compile-time) وأثناء التشغيل (Run-time) عبر نظام معالجة الاستثناءات (Exception Handling).

11. Secure (آمنة)[cite: 2]

لأن برامج جافا تعمل داخل بيئة معزولة (Sandbox) داخل آلة جافا الافتراضية ولا تتعامل مباشرة مع عناوين ذاكرة نظام التشغيل.

  1. الكود المصدري Java Code (.java): هو الملف النصي الذي تكتبه بيدك. لاحقته دائماً .java.
  2. مترجم جافا JAVAC compiler: أداة تقوم بترجمة الكود المصدري دفعة واحدة وتفحص الأخطاء القواعدية.
  3. الشفرة الوسطية Byte Code (.class): ناتج عملية الترجمة ليس كود آلة خاصاً بـ Windows أو Linux، بل هو كود وسيط يسمى Byte Code ويحمل اللاحقة .class. هذا الملف هو السر وراء استقلالية جافا عن المنصة.

⚠️ تنبيه امتحاني دقيق: ملف الـ Byte Code (.class) هو مستقل عن المنصة (Platform Independent)، بينما الـ JVM نفسها هي معتمدة على المنصة (Platform Dependent) لأن لكل نظام تشغيل (Windows, Linux, Mac) نسخة JVM مخصصة له[cite: 2].

الملاحظة 1 (حساسية الأحرف - Case Sensitivity):

الملاحظة 2 (التعليقات - Comments):

  2. تعليق على مجموعة من الأسطر (Multi-line comment): يبدأ بـ /* وينتهي بـ */ مثل مجموعة الأسطر من 7 إلى 9.

• فائدة متقدمة للتعليقات (Javadoc): كل ما يُكتب كتعليق يتجاهله مترجم جافا ولا يقرأه، ولكن عندما يبدأ التعليق بـ /** وينتهي بـ */ (كما في الأسطر 7-9 حيث توجد @param args)[cite: 3]، يمكن الاستفادة منه باستخدام أداة متقدمة في جافا (تسمى javadoc) تقوم بتجميع جميع تعليقات البرنامج لتوليد توثيق كامل (Documentation) عنه على شكل صفحات ويب[cite: 3].

5. أقواس الصف، الأشكال الصحيحة والخاطئة للدالة main، ومحارف الهروب

• أقواس الصف: السطر الخامس ينتهي بقوس البداية { الذي يعلن بدء جسم الصف، ويجب إغلاقه بقوس النهاية } في السطر 17[cite: 4]. (في النص العربي للمحاضرة انعكس اتجاه القوسين بسبب التنسيق العربي للوورد، لكن القاعدة البرمجية الثابتة هي الفتح بـ { والإغلاق بـ }).

• السطر 10 (الدالة main): هي نقطة البداية (Entry Point) التي يبدأ من عندها تنفيذ أي تطبيق جافا[cite: 4]. قاعدة ذهبية للامتحان: يمكن لتطبيق جافا أن يحتوي على أكثر من صف، ولكن ضمن التطبيق الواحد (أو نقطة التشغيل الواحدة) يجب أن تتواجد الدالة main لتنفيذ البرنامج، وفي حال عدم وجود هذه الطريقة (Method) لن يتم تنفيذ التطبيق مطلقاً[cite: 4].

• الكلمة المحجوزة void: تعني أن هذه الدالة ستقوم بأداء مهمة ما (طباعة نتيجة، طباعة ناتج ضرب، طباعة متوسط...) ولكنها لا تعيد قيمة فعلية معروفة (لا تحتوي على return value;)[cite: 4].

• الكلمة المحجوزة static: تجعل الدالة تابعة للصف مباشرة بحيث تستطيع الـ JVM استدعاءها وتشغيل البرنامج فورياً دون الحاجة لإنشاء غرض (Object) من الصف أولاً.

✅ الأشكال الـ 7 الصحيحة للتصريح عن الدالة main:

  1. public static void main(String[] args) الشكل القياسي الأشهر (قوسا المصفوفة ملتصقان بـ String).
  2. public static void main(String []args) قوسا المصفوفة ملتصقان باسم المتغير args (صحيح).
  3. public static void main(String args[]) قوسا المصفوفة بعد اسم المتغير args على طريقة لغة C (صحيح).
  4. public static void main(String... args) استخدام ميزة Varargs عبر ثلاث نقاط ... بدلاً من أقواس المصفوفة (صحيح جداً).
  5. static public void main(String[] args) تبديل موقع public و static قبل void (صحيح).
  6. public static final void main(String[] args) إضافة final لمنع إعادة تعريف الدالة (صحيح ومسموح).
  7. final public static void main(String[] args) تبديل مواقع final و public و static قبل void (صحيح)[cite: 4].

❌ الأشكال الـ 4 الخاطئة (ولماذا هي خاطئة؟):

  1. public void main(String[] args) خاطئ بسبب غياب الكلمة static (لن تتمكن الـ JVM من تشغيل البرنامج).
  2. static void main(String[] args) خاطئ بسبب غياب الكلمة public (يجب أن تكون عامة لتراها الـ JVM).
  3. public void static main(String[] args) خاطئ قواعدياً (Syntax Error) لأن نمط الإرجاع void يجب أن يأتي مباشرةً قبل اسم الدالة main ولا يجوز فصلهما بـ static.
  4. abstract public static void main(String[] args) خاطئ لأنه لا يجوز جمع abstract مع static، ولأن main يجب أن تمتلك جسماً { }[cite: 4].

7. تحويل الأنماط (Typecasting) والمعاملات (Operators)

هذه الصفحة تحتوي على أهم الخدع البرمجية (Code Tracing Tricks) التي تأتي كأكواد يُطلب منك إيجاد خرجها أو تحديد سطر الخطأ فيها. لنشرح الأمثلة الستة بالتفصيل الممل:

أولاً: التحويل بين الأنماط (التوسيع Widening مقابل التضييق القسري Narrowing):

1. جمع عددين وطباعة الناتج 
class Simple {
    public static void main(String[] args) {
        int a = 10;
        int b = 10;
        int c = a + b;
        System.out.println(c);
    }
}
// Output: 20
2. التوسيع التلقائي (Widening) 
class Simple {
    public static void main(String[] args) {
        int a = 10;
        float f = a; // تحويل ضمني تلقائي
        System.out.println(a);
        System.out.println(f);
    }
}
// Output:
// 10
// 10.0
3. التضييق القسري (Narrowing) 
class Simple {
    public static void main(String[] arg) {
        float f = 10.5f;
        // int a = f; // Compile time error!
        int a = (int)f; // قسري صريح
        System.out.println(f);
        System.out.println(a);
    }
}
// Output:
// 10.5
// 10

• في التوسيع (Widening) من int إلى float، تقوم جافا بالتحويل تلقائياً وضمنياً دون اعتراض وتطبع 10 ثم 10.0[cite: 6].
• في التضييق (Narrowing) من float إلى int، كتابة int a = f; مباشرة تعطي Compile time error لمنع ضياع الفاصلة العشرية دون إذن. الحل هو التحويل القسري int a = (int)f; الذي يقطع الجزء العشري بالكامل فيطبع 10.5 ثم 10[cite: 6].

ثانياً: معاملات الزيادة والنقصان (++ و --) وخدعة النمط short:

• الزيادة القبلية ++x (Pre-increment): زِد قيمة x في الذاكرة بمقدار 1 أولاً، ثم استخدم القيمة الجديدة في التعليمة الحالية.

• الزيادة البعدية x++ (Post-increment): استخدم قيمة x القديمة في التعليمة الحالية أولاً، وبعد انتهاء هذه الجزئية زِد قيمتها في الذاكرة بمقدار 1.

مثال الزيادة والنقصان المتتالي 
int x = 10;
System.out.println(x++); // يطبع 10، ثم تصبح بالذاكرة 11
System.out.println(++x); // يزيدها أولاً لتصبح 12، ويطبع 12
System.out.println(x--); // يطبع 12، ثم تنقص بالذاكرة لتصبح 11
System.out.println(--x); // ينقصها أولاً لتصبح 10، ويطبع 10
مثال التعابير المركبة (سؤال مذاكرة شهير!) 
int a = 10;
int b = 10;
System.out.println(a++ + ++a); // 10 + 12 = 22
System.out.println(b++ + b++); // 10 + 11 = 21

• تفصيل حساب a++ + ++a = 22: الجزء الأول a++ يعوض بقيمته الحالية 10 وتصبح a بالذاكرة 11. الجزء الثاني ++a يزيد 11 أولاً لتصبح 12 ويعوض بـ 12. المجموع: 10 + 12 = 22[cite: 6].

• تفصيل حساب b++ + b++ = 21: الجزء الأول b++ يعوض بـ 10 وتصبح b بالذاكرة 11. الجزء الثاني b++ يعوض بالقيمة الحالية 11 ثم تصبح بالذاكرة 12. المجموع: 10 + 11 = 21[cite: 6].

🔥 أخطر خدعة في المذاكرة: ترقية النمط short في العمليات الحسابية (أسفل صفحة 11):
1. الإسناد المركب (+= و -=)
int a = 10;
int b = 20;
a += 4; // a = 10 + 4 = 14
b -= 4; // b = 20 - 4 = 16
System.out.println(a); // 14
System.out.println(b); // 16
2. كود يسبب خطأ ترجمة!
short a = 10;
short b = 10;
// a += b; // internally fine!
a = a + b; // Compile time error!
// because 10+10=20 now int
System.out.println(a);
3. تصحيح الخطأ بـ (short)
short a = 10;
short b = 10;
a = (short)(a + b); // 20 converted
System.out.println(a); // 20

القاعدة الهندسية (Type Promotion): في جافا، أي عملية حسابية ثنائية (+, -, *, /) تجري على متحولات صحيحة أصغر من int (وهي byte أو short أو char)، يقوم المترجم تلقائياً بترقية الناتج إلى النمط int! لذلك a + b يصبح نوعه int، ومحاولة إسناده إلى short a عبر a = a + b; تعطي Compile time error[cite: 6]. بينما a += b; تعمل بنجاح لأن المعامل += يقوم بتحويل قسري ضمني داخلياً a = (short)(a + b)[cite: 6]!

import java.util.Scanner;
public class Fibonacci {

        int num2 = 1;
        int result = 0;
        int range = 0;
        Scanner scan = new Scanner(System.in);
        System.out.println("Enter the Fibonacci series length:");

    }
}

import java.util.Scanner;
public class PalindromeNumber {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);
        System.out.print("Input: ");
        int num = scan.nextInt();

        int original = num;
        int reversed = 0;

        while (num > 0) {
            int digit = num % 10;
            reversed = (reversed * 10) + digit;
            num = num / 10;
        }

        if (original == reversed)
            System.out.println("Output: palindrome number");
        else
            System.out.println("Output: not palindrome number");
    }
}

                if (arr[j] > arr[j + 1]) {
                    temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }

            System.out.print(k + " ");
        }
    }
}

BinarySearchHw2.java 
import java.util.Scanner;
public class BinarySearchHw2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter the number of elements (N): ");
        int n = sc.nextInt();
        double[] arr = new double[n];

        System.out.println("Enter " + n + " real numbers:");
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextDouble();
        }

        // 1. ترتيب المصفوفة تصاعدياً (شرط أساسي قبل البحث الثنائي!)
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    double temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }

        // 2. البحث الثنائي (Binary Search)
        System.out.print("Enter a real number to search for: ");
        double key = sc.nextDouble();

        int low = 0, high = n - 1, foundIndex = -1;
        while (low <= high) {
            int mid = (low + high) / 2;
            if (arr[mid] == key) {
                foundIndex = mid;
                break;
            } else if (key > arr[mid]) {
                low = mid + 1; // البحث في النصف الأيمن
            } else {
                high = mid - 1; // البحث في النصف الأيسر
            }
        }

        if (foundIndex != -1)
            System.out.println("Found at index: " + foundIndex);
        else
            System.out.println("Not found in the array");
    }
}

6. الطرائق (Methods): تعريفها واستدعاؤها

[Access_Specifier] [static] [Return_Type] Method_Name([parameters]) { Method_Body }[cite: 21]

• Access_Specifier (محدد الوصول): إما private (مرئية فقط داخل الصف الذي عُرفت فيه)، أو public (مرئية في أي مكان في البرنامج)، أو بدون كتابة محدد (Default) وتكون مرئية فقط داخل الحزمة (Package) التي يتبع لها الصف.

• static (ثابت): تُستخدم لتعريف الطرق ليتم استخدامها داخل الصف مباشرة دون أن ترتبط بأي كائن (Object) من نوع هذا الصف.

• Return_Type (نوع الإرجاع): يحدد نوع البيانات المرجعة باستخدام الكلمة المحجوزة return، وإذا كانت لا ترجع أي قيمة يجب أن يكون void.

• parameters (المعاملات - سؤال مذاكرة هام!): عند تعريف الطريقة تسمى بالمعاملات الشكلية (Formal Parameters)، وعند استدعاء الطريقة تسمى بالمعاملات الفعلية (Actual Parameters)[cite: 21]!

أشكال المعاملات الفعلية عند الاستدعاء:

  • قيم ثابتة: مثل sum1(5, 6);
  • متغيرات: مثل sum1(x, y);
  • استدعاء لطريقة أخرى: مثل sum1(sum2(z, 4), 6);[cite: 22]

حالتا استدعاء الطرق حسب الإرجاع:

  • طرق لا ترجع قيماً (void): يجب ألا يتم إسنادها إلى متغير ولا استخدامها في تعبير.
  • طرق ترجع قيماً: تُسند إلى متغير، أو تُستخدم في تعبير، أو تُمرر في استدعاء طريقة أخرى[cite: 22].

1. الفلسفة الأساسية للبرمجة غرضية التوجه (OOP) وبنية الصف (Class)

يعتمد مفهوم البرمجة غرضية التوجه على الفكرة الأساسية التي تقول بأن كل البرامج هي محاكاة حاسوبية لأغراض وأشياء من العالم الحقيقي أو لمفاهيم مجردة في هذا العالم[cite: 28]. وتتمتع الأغراض (Objects) بأربع صفات ومفاهيم أساسية:

1. الهوية (Identity)

لكل غرض خصوصية وهوية فريدة تميزه عن غيره في الذاكرة (حتى لو تشابهت بياناته مع غرض آخر).

2. الحالة (Data Fields / State)

لكل غرض متحولات (حقول بيانات) تعكس حالة هذا الغرض وخصائصه في لحظة معينة.

3. السلوك (Methods / Behavior)

لكل غرض بعض طرائق المعالجة (الدوال) التي تعبر عن سلوكه والعمليات التي يمكنه القيام بها.

4. الانتماء للصف (Class)

كل غرض ينتمي إلى شكل (قالب) من أشكال البيانات يُدعى بالصف (Class)، ونقول إن الغرض هو شبيه صفه ويشكل مثالاً له (Instance of a Class)[cite: 28].

مما يتألف الصف (Class) في جافا؟

يتألف الصف من: (1) مجموعة حقول البيانات (Data Fields)، (2) مجموعة الطرائق المتعلقة بالصف (Methods)، إضافة إلى (3) البواني (Constructors) وهي تحمل اسم الصف نفسه تماماً ولا تملك نمط إرجاع (حتى void لا يُكتب لها!) وتقوم بتشييد وبناء الأغراض من الصف، وجميعها يمكن أن تُعرّف بأنها عامة أو خاصة أو محمية (public - private - protected)[cite: 28].

    private double real;
    private double imag;

    // 1- باني ذو وسطاء
    public Complex(double real, double imag) {
        this.real = real;
        this.imag = imag;
    }

    // 2- طريقة لتعديل عدد عقدي
    public void setComplex(double real, double imag) {
        this.real = real;
        this.imag = imag;
    }

    // 3- طرائق للحصول على الجزء الحقيقي أو الجزء التخيلي
    public double getReal() { return this.real; }
    public double getImag() { return this.imag; }

    // 4- طريقة لطباعة عدد عقدي
    public void printComplex() {
        if (imag >= 0)
            System.out.println(real + " + " + imag + "i");
        else
            System.out.println(real + " - " + (-imag) + "i");
    }

    // 5- طريقة لجمع عددين عقديين (تستقبل غرضاً وتعيد غرضاً جديداً)
    public Complex add(Complex other) {
        return new Complex(this.real + other.real, this.imag + other.imag);
    }

    // 6- طريقة لحساب طويلة عدد عقدي: sqrt(real^2 + imag^2)
    public double getMagnitude() {
        return Math.sqrt((this.real * this.real) + (this.imag * this.imag));
    }

    public static void main(String[] args) {

        Complex c2 = new Complex(1.5, 2.5);

التمرين 2: صف الأعداد الكسرية (Fraction) بطرائقه الـ 5 الكاملة (شاملاً اختزال الكسر بالقاسم المشترك الأعظم GCD وتوحيد المقامات في الجمع)[cite: 33]:

Fraction.java 
public class Fraction {
    private int num; // البسط
    private int den; // المقام

    // 1- باني ذو وسطاء (مع منع القسمة على صفر)
    public Fraction(int num, int den) {
        this.num = num;
        this.den = (den == 0) ? 1 : den;
    }

    // 2- طريقة لتعديل عدد كسري
    public void setFraction(int num, int den) {
        this.num = num;
        if (den != 0) this.den = den;
    }

    // 3- طرائق للحصول على قيمة البسط أو المقام
    public int getNum() { return this.num; }
    public int getDen() { return this.den; }

    // دالة مساعدة لحساب القاسم المشترك الأعظم (GCD) لاختزال الكسر
    private int gcd(int a, int b) {
        a = Math.abs(a); b = Math.abs(b);
        int g = 1;
        for (int i = 1; i <= a && i <= b; i++) {
            if (a % i == 0 && b % i == 0) g = i;
        }
        return g;
    }

    // 4- طريقة لطباعة عدد كسري بشكل مختزل
    public void printReduced() {
        int g = gcd(this.num, this.den);
        System.out.println((this.num / g) + " / " + (this.den / g));
    }

    // 5- طريقة لجمع عددين كسريين (توحيد المقامات)
    public Fraction add(Fraction other) {
        int newNum = (this.num * other.den) + (other.num * this.den);
        int newDen = this.den * other.den;
        return new Fraction(newNum, newDen);
    }

    public static void main(String[] args) {
        Fraction f1 = new Fraction(4, 8);
        Fraction f2 = new Fraction(2, 6);
        f1.printReduced(); // 1 / 2
        Fraction sum = f1.add(f2);
        sum.printReduced(); // 5 / 6
    }
}
